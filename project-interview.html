Overview

An interactive quiz platform offering a personalized, adaptive learning experience for technical topics. Users choose specific topics and set their confidence levels, then practice through flash cards, case studies, and open-ended questions. It is aimed at students and job-seekers preparing for technical interviews, exams, or skill refreshers across areas like Machine Learning, Probability, SQL, and Data Structures.

Core concepts

  • Targeted practice — adaptive quizzes across selectable topics build understanding where it matters most
  • Open-ended thinking — questions that challenge users to explain concepts clearly and confidently
  • Confidence insights — a visual overview of strengths and weaknesses that updates as knowledge evolves
  • Prompt engineering — structured prompts guide the Gemini API to behave as a consistent, fair interviewer

System & data pipeline

Question content was sourced via API calls and web scraping (Reddit, GeeksforGeeks) and processed through an AWS pipeline — SageMaker Studio notebooks for ETL, S3 for storage, and Amazon RDS as the backing database. The Flask front end was hosted on GitHub and deployed via Render, keeping the whole system at zero incurring cost.

Development notes

The core loop sends the conversation history plus a structured system prompt to Gemini on each turn, maintaining interviewer consistency and adjusting difficulty to the user's confidence:

import google.generativeai as genai

model = genai.GenerativeModel("gemini-pro")
chat = model.start_chat(history=session_history)

response = chat.send_message(
    f"User answered: {user_input}. Evaluate and ask the next question."
)
# Store response + update confidence score
