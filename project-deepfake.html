Overview

Built an ensemble deep learning classifier that combines a Vision Transformer (ViT) and EfficientNet to detect AI-generated or manipulated images, reaching 92.25% classification accuracy. The model is deployed as a live web interface on Hugging Face Spaces, allowing anyone to upload an image and receive an authenticity verdict with visual explainability output. The pipeline was later extended to video inputs.

Architecture & data flow

From an uploaded image or video to a verdict with evidence. Select a stage or run the trace.

Core concepts

  • Ensemble architecture — ViT captures global attention patterns while EfficientNet handles local texture artifacts typical of generated faces
  • Visual explainability via Grad-CAM heatmaps, highlighting the facial regions that drove each classification and improving end-user trust
  • Threat model — misuse and failure modes considered up front: manipulated or adversarial media, false positives and negatives, and handling of user-uploaded images and video — with Grad-CAM heatmaps giving reviewers evidence to check each verdict
  • Video support — extracts frame-level samples and classifies each through the ensemble, enabling authenticity verification across video as well as static images
  • Baseline benchmarking — a Keras CNN baseline compared against the PyTorch ensemble, with training accuracy/loss curves and confusion matrices in Matplotlib validating the ensemble's advantage
  • Transfer learning from pretrained ImageNet weights, fine-tuned on a labeled real/fake image dataset
  • Live inference deployed via Gradio on Hugging Face Spaces with a real-time web UI

Development notes

The ensemble combines soft-voting across both models. Grad-CAM is applied post-inference to produce the visual explanation overlay:

# Ensemble soft voting
vit_prob = vit_model(image)
eff_prob = eff_model(image)
final_pred = (vit_prob + eff_prob) / 2

# Grad-CAM for explainability
cam = GradCAM(model=vit_model, target_layer="blocks[-1]")
heatmap = cam(input_tensor=image)
"In an era of synthetic media, the ability to verify what's real is infrastructure."

The live interface on Hugging Face lets users drag and drop any image to receive a real/fake probability score alongside a heatmap showing which regions the model flagged as manipulated.
