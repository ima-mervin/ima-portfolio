Overview

Built a full-stack web application that takes budget and dietary constraints as inputs and generates matching recipes via a custom filtering algorithm. The app was containerized with Docker and deployed on Microsoft Azure, with usability testing informing UI improvements that raised navigation efficiency by 20%.

Core concepts

  • Constraint-based filtering — matches ingredients to recipes based on budget ceiling, dietary restrictions, and pantry availability
  • Usability testing — sessions to identify UI friction points, leading to documented UX improvements
  • Containerized deployment — Docker image deployed to Azure for scalable, reproducible hosting
  • Full-stack architecture — Python/Flask backend with a JavaScript/HTML/CSS front end connected via a REST API

Development notes

The core filtering algorithm scores recipes against user constraints using a weighted match function, returning ranked results:

def filter_recipes(budget, pantry, restrictions, recipes):
    results = []
    for recipe in recipes:
        score = compute_match(
            budget=budget,
            ingredients=recipe["ingredients"],
            pantry=pantry,
            restrictions=restrictions
        )
        if score > THRESHOLD:
            results.append((score, recipe))
    return sorted(results, reverse=True)
